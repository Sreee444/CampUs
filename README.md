# CampUs

A campus collaboration platform built to connect **students, faculty, alumni, and admins** in one unified system for communication, academic engagement, events, projects, mentoring, and community interaction.

---

## 📌 Project Overview

**CampUs** is a mobile-first campus networking and collaboration application developed as a mini project.  
It provides role-based access and includes key modules such as:

- Authentication & user profiles
- Campus feed and announcements
- Events and reminders
- Discussion forums
- Project/team collaboration
- Chat and notifications
- Mentorship support
- Admin controls
- AI-powered recommendation components

---

## ✨ Implemented Features

## 1) Authentication & User Management
- Secure login system
- Role-based access (Student / Faculty / Alumni / Admin)
- Session handling and protected routes
- User account lifecycle management

## 2) Profile Management
- View and edit personal profile
- Academic/professional details management
- Public profile visibility
- Dashboard-based profile access

## 3) Campus Feed & Announcements
- Create and view feed posts
- Academic/community announcements
- Role-based content visibility and moderation paths

## 4) Event Management
- Event publishing and listing
- Event detail pages
- Registration workflow
- Calendar-style event tracking/reminders

## 5) Discussion Forum
- Topic-wise academic discussions
- Community interaction threads
- Structured participation module for users

## 6) Project & Team Formation
- Project creation and participation
- Team formation workflow
- Project detail management pages

## 7) Messaging & Communication
- In-app chat module
- Direct messaging support
- Communication workflow integrated with user discovery

## 8) Notifications
- Event/user activity-driven notification support
- In-app update awareness across major modules

## 9) User Discovery
- Discover users based on system context
- Supports collaboration, mentorship, and communication flows

## 10) Mentorship Support
- Mentor/mentee interaction pathways
- Built to connect seniors/alumni/faculty with students

## 11) Admin Module
- Admin dashboard
- User/content-level management functions
- Monitoring and moderation support

## 12) AI Recommendation Module
- AI-assisted recommendation features integrated for platform intelligence
- Used in collaboration/engagement-oriented flows

---

## 🧱 Technology Stack

- **Frontend (Mobile):** React Native, Expo, TypeScript  
- **State Management:** Zustand, Context API  
- **Backend:** Node.js, Express  
- **Database:** PostgreSQL (via Supabase stack)  
- **Auth & Backend Services:** Supabase
